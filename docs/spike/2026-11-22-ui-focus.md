# 2026-11-22 界面聚焦：自签 + 定位（0.5.0 / 32）

用户明确：核心只要**自签**和**定位**，其他都是可选项；界面样式和功能点优化即可。本次只改界面层，签名、安装、续签、定位、证书管理的底层逻辑与测试不变。

## 页面结构：4 个标签 → 3 个

| 之前 | 之后 |
|---|---|
| 安装 | **签名**（第一个标签） |
| App（续签、自身续签、证书管理、设备 App） | 已签名 App 列表并入**签名**页；其余移入**设置** |
| 定位 | **定位**（第二个标签） |
| 连接 | 移入**设置 → 连接检测** |

## 签名页

1. **准备**：配对文件、Apple ID、设备地址三行，已完成显示绿色勾，未完成显示橙色并可直接点开设置；设备地址可就地修改，安装时验证过的设备显示"已验证本机"。
2. **安装 App**：IPA 卡片（名称、点按更换）+ 全宽"签名并安装"主按钮。
3. **进度**：分 5 步显示（检查 IPA → 连接设备 → 准备证书 → 签名 → 安装），由 `SigningViewModel.stage` 映射；安装中显示上传进度条。
4. **结果**：成功后显示有效期，并提示免费账号约 7 天、可在下方续签。
5. **已签名的 App**（`ManagedAppsSection`）：LocSign 自身在第一行（标"本 App"），其余按到期时间排序；每行显示"N 天/小时后到期"（48 小时内橙色、过期红色）、"续签"按钮和单 App 自动续签开关；长按清除记录；开启自动续签时表头有"检查到期"。续签时的证书撤销确认仍在此处弹出（`manualConfirmationAvailable` 改为签名标签可见时为真）。
6. **高级：使用自己的证书和描述文件**：手动签名折叠在页底。

## 定位页

- 顶部搜索框（可清除、回车搜索），结果最多 8 条，选中后收起。
- 地图放大到 340 pt，提示"点击地图选点"。
- **常用地点**：收藏与最近使用改为横向小卡片，当前坐标对应的卡片高亮；长按重命名/删除/清空。
- **底部固定操作栏**：当前地点名或坐标、状态、错误、"应用定位"主按钮、"恢复真实"按钮，处理中可取消。
- 蜂窝数据待恢复时显示橙色提示卡。
- **高级**（默认收起）：地图区域、坐标类型、手动经纬度、连接方式、无 Wi-Fi 辅助快捷指令说明、首次使用说明。
