# 2026-11-22 定位收藏与最近使用

目标版本：0.4.12（31）。11-20 已确认的需求：定位页可收藏地点、保留最近 20 次成功应用的地点；点选只填入坐标，点"应用定位"后才发送到设备。测试先于实现提交（`6cc3292`，RED），本次补上实现，CI #79/#80 中 `LocationViewModelTests` 第 13、32 行的两个失败即由此而来。

## 行为

- **收藏**：收藏当前坐标并命名；可重命名、删除。同一坐标、同一坐标类型只保存一次，再次收藏更新名称与地图区域；数值相同但坐标类型不同（WGS-84 / GCJ-02）视为两个地点。
- **最近使用**：只有设备确认、未中断的"应用定位"才记入；恢复真实定位、失败、取消都不记。重复使用同一地点移到最前并保留原记录；最多 20 条。可单条删除或清空，不影响收藏。
- **名称**：来自搜索结果名或收藏名；手动修改经纬度或切换坐标类型后，名称自动清除，避免旧名字配新坐标。无名称时以坐标作为名称。
- **坐标**：保存用户输入/选中的原始坐标和坐标类型，不保存转换后的 GPS 值，重新应用时按原类型重新换算。
- **操作中**：应用/恢复进行时不能点选地点或修改收藏。

## 存储

- `UserDefaults` 键 `location.savedPlaces.v1`，一个 JSON：`{"favorites": [...], "recents": [...]}`。每项含 `id`、`name`、`latitude`、`longitude`、`coordinateSystem`、`mapRegion`。
- 每次修改先写入完整新值再更新界面。
- 已保存的数据无法解析、坐标越界、名称无效、id 重复或最近使用超过 20 条时，整体视为不可用：界面显示提示，列表为空，**拒绝一切写入**，原数据不被覆盖。
- 记入最近使用失败不影响定位结果：状态仍显示"设备已接受"，只在收藏区显示提示。
