# 0.3.0 一键安装

## 已批准范围

首次配置 Apple ID、团队、配对文件及设备地址；之后选择 IPA、一键完成设备认证、材料复用或申请、签名和安装。记住每个应用/团队的签名标识；LocalDevVPN 由用户开启，撤销证书仍逐次确认精确列表。

## 实现

- InstallationSettings 在两个页面共享设备设置与操作锁；配对文件使用 Application Support、原子写入、completeFileProtection 和排除备份。替换校验/写入失败保留原记录；可单独清除。
- AppleIDProvisioningModel 保存提供方开关、与准确地址绑定的同意及每个账号的团队。密码不保存，团队恢复时仍校验属于当前账号。
- SigningViewModel 在同一个受保护操作中自动认证、先查缓存、必要时申请、签名、上传安装。取消或迟到结果不会触发下一个阶段；失败保留已生成签名文件；没有自动安装重试。
- 缓存不匹配或正常到期作为缓存未命中；CMS、私钥及其他校验失败保持错误，不静默发起新申请。
- 签名页以一键安装为主，原手动签名保留在高级选项。账号页承接登录、2FA 和撤销确认，关闭确认页不误取消外部任务。
- 不改动已通过真机的心跳、TLS 校验及签名资源封装路径。

## 升级与验收

使用原 Apple ID/Bundle ID 覆盖更新。首次需重导配对文件；旧版使用个人签名标识的 IPA 需首次选择原标识，成功签名后记住。开启 VPN，选择 Feather，点一键安装，确认主屏幕可打开。重启 LocSign 后再选同一 IPA，检查设备设置、团队、个人标识恢复；观察有效材料复用无需手动加载描述文件。
