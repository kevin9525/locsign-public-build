# 一键连接自检与排查入口（0.5.4 / 36）

用户于 2026-11-27 确认继续“一键连接自检 + 签名/定位排查入口”。本轮在 `feat/connection-self-check` 工作树开发，基线为已交付 0.5.3 的 `67d2f68`。

## 行为

连接页增加一次完成的自检：先检查字面 IP 和设备响应，再使用已保存的配对文件验证设备身份、文件传输和安装服务。无配对时仍可检查设备是否响应，并提示导入文件。逐项显示通过、失败、取消或未执行；某一步失败后停止后续网络检查。当前步骤与失败处理入口对应，原始错误经脱敏后显示。

签名页的准备区和失败区、定位页工具栏和失败区提供排查入口。自检页支持修正地址、导入配对、重新检查、进入本 App 系统设置及诊断日志。正在签名或定位操作时禁止启动自检；检查过程中也阻止新的设备操作。离开检查页面取消正在运行的检查，等待当前有超时限制的网络步骤结束后释放操作锁。

自检只连接和关闭现有设备服务，不上传 IPA、不发送安装或定位命令、不切换 VPN 或蜂窝数据。连接失败不直接判定 VPN 关闭、权限被拒或配对已失效。安装服务连通不能证明定位开发者服务已就绪，成功结果也不代表实际安装或 GPS 已验证；页面明确说明这些边界。

检查结果仅是本次检查的记录。改变地址、替换配对或重新检查时清除旧结果；取消不得产生新的成功结论。用户从系统设置返回后可手动重查。

## 真机验收

1. 从签名准备区进入连接自检，已有有效配对和网络时逐项显示结果；验证不触发安装，也不改变当前地图选点。
2. 缺少配对文件时仍能检查设备响应，随后提示导入；导入后重新自检，旧结果被清除。
3. 连接超时、配对认证失败或服务不可用时，失败项和下一步提示准确，后续项显示未执行。
4. 取消后不显示最终全部通过；等待结束后可再次检查。检查期间签名、续签、定位操作不能并发启动。
5. 修改地址或配对后，旧成功结果消失；重新检查失败时不保留上一轮全部通过的状态。
6. 从签名/定位错误区进入自检或诊断日志，并可正常返回；错误详情、步骤状态在大字体下可阅读。
