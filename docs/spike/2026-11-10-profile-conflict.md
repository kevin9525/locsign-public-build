# 0.3.1 描述文件创建冲突处理

## 现场证据

2026-11-10，用户在 0.3.0（16）的一键安装中选择 Feather.ipa，收到“创建描述文件失败：Apple Developer Services 请求被拒绝（HTTP 409）”。USB 只读检查确认手机安装版本；用户确认已开启个人签名标识，且沿用之前成功的同一标识。

旧传输层在返回非成功状态时丢弃 profile 错误响应，无法还原本次 Apple 原因。代码每次创建使用相同显示名称；这说明可能遇到名称冲突，但不是现场根因证据。此前签名产物中的描述文件到期时间晚于本次反馈，仍不能证明当前远端证书有效或材料可复用。

## 修复范围

- 在 live HTTP adapter 和注入传输的 gateway middleware 中，将有界的 profile HTTP 409 响应映射为固定类别。响应原文、名称、账号、设备及证书值不进入错误或日志。
- P01 表示明确名称冲突：必须具有名称字段指针、准确错误代码和完整匹配的重名描述，且所有错误均为重名。只允许重试一次，修改 profile 显示名称；应用标识、证书、设备和类型保持原值。
- P02 表示已有开发描述文件，P03 表示数量限制，P04–P07 分别表示证书、设备、应用标识及类型关联被拒绝，P00 表示未识别的冲突。混合或未知原因不授权再次创建；无法解析的响应保留 HTTP 状态错误。
- 创建遇到 409 时重新查询一次已有描述文件，仍使用原来的 CMS、团队、应用、设备、到期时间、证书与私钥验证。仅完整验证通过才复用；查询失败或没有匹配项时保留原创建错误，取消正常传播。
- 不自动删除描述文件、撤销证书或更换应用标识。已保存的私钥和证书继续保留，避免失败后丢失可恢复材料。

## 真机复测

使用原 Apple ID 和原 LocSign 应用标识覆盖安装 0.3.1（17），保留现有账号与配对资料。保持 LocalDevVPN 开启、手机解锁、相同团队及 Feather 个人签名标识，选回原 Feather.ipa，点击“一键安装”。无需手动测连接或加载描述文件。

若成功，分别确认安装完成及 Feather 能打开；若失败，记录完整步骤、P00–P07 分类及 HTTP 状态。重名恢复和严格材料复用已纳入实现，但实际 Apple 限制可能仍需进一步处理；自动化测试不能替代此次手机验收。
