# 诊断日志（0.5.2 / 34）

用户于 2026-11-26 反馈“现在版本可正常使用”，并要求继续开发。该反馈没有逐项确认具体版本及 Seal、扩展、后台续签等场景。本轮接续原设计 §6.6 的“日志落盘可导出”和 M3 错误引导，补齐已有日志的应用内入口。

## 使用方式

“设置 → 关于 → 诊断日志”显示最近记录，右上角可刷新或导出为 UTF-8 文本。导出使用系统文件保存界面，内容与当前页面快照一致；用户自行选择保存位置。读取失败显示重试提示，空日志显示空状态。

保留 `Documents/logs/app.log` 路径，旧日志可直接读取。签名失败会记录已脱敏错误；定位记录开始、设备接受、取消/失败和连接中断，不主动记录选点坐标与地点名称。日志只是操作诊断，不代替地图中的真实位置验收。

## 实现边界

- `DiagnosticLogStore` 串行处理写入和快照读取，快照包含此前已经提交到队列的记录。
- 日志文件最多 512 KiB，超过时原子保留最近的完整记录；旧版无界日志在下一次写入时收敛到上限。读取旧文件只读取有界尾部。
- 页面与导出最多 128 KiB；单条记录最多 16 KiB，超长内容先整条脱敏再截断，并维持 UTF-8 完整性。
- 重用现有敏感字段/邮箱/设备标识脱敏，并在快照读取时重新处理旧日志和 PEM 私钥块。导出仅包含当前显示的日志文本。
- 磁盘写入失败不打断签名或定位，但日志页会显示读取失败；后续成功写入恢复正常。
